Sign in with the local dashboard key to manage your bot's servers, moderation, applications, and settings.

🔑 Where do I find the dashboard key?
  1. Open a terminal on the machine that runs the bot (this page only listens there).
  2. Run the command for your install: sentinel --dashboard-tokenInstalled app (.dmg, .deb, Windows Setup) python3 bot.py --dashboard-tokenRunning from source
  3. Copy the key that is printed (the first run creates it if needed) and paste it above.

The key is also saved as dashboard_token in the bot's config.json — run sentinel --paths (or python3 bot.py --paths) to see where that file lives. This is not your Discord bot token.
